## Collected Functionality (source of truth)
Primary UI driver: `src/ReactImageEditor.tsx`

### Viewer (zoom/pan)
- Wheel/trackpad zoom to cursor (`useCanvasZoomPan`) + pinch zoom.
- Double-click / double-tap toggles fit vs 2x zoom.
- Drag-to-pan with inertia.
- Keyboard: `Cmd/Ctrl +`, `Cmd/Ctrl -`, `Cmd/Ctrl 0`.

### Crop + straighten
- Crop mode toggle + overlay with drag + 8 resize handles.
- Aspect ratio presets + custom ratio dialog; optional aspect lock.
- Rotation range -45..45; constrain crop option.
- Apply/Reset crop; Reset Rotation.
- Crop-mode shortcuts: `[`/`]` (1° or 5° with Shift), `R` resets rotation.

### Export / download
- Formats: PNG, JPEG.
- JPEG quality 10..100 (default 92).
- Crop must be applied before export (Download disabled during crop mode).
- JPEG exports with white background; PNG keeps transparency.

### Adjustments (non-destructive, stored as `ImageEditorEdits`)
- White balance: presets + temperature (2000..10000) + tint (-100..100) + eyedropper; Esc cancels pick.
- Tone: exposure (-2..2), contrast/highlights/shadows/whites/blacks (-100..100).
- Color: vibrance/saturation (-100..100).
- Presets: built-in preset list + intensity 0..100; applied presets bake into manual sliders.
- Color mixer: per-band HSL for 8 bands (h/s/l -100..100).
- Point color: hue pick (normalized 0..1) + shifts (-100..100) + range (0..100); Esc cancels pick.
- Tone curve: Point + Region/parametric, RGB + per-channel; parametric sliders -100..100.
- Details: Sharpen (amount 0..150, radius 0.5..3, detail 0..100, masking 0..100) + Denoise (0..100).

### Geometry & optics
- Perspective: vertical/horizontal/aspect (-100..100).
- Lens corrections: distortion (-100..100) + chromatic aberration toggle.
- Optics: vignette (-100..100), grain (0..100), dehaze (-100..100).
- Auto-straighten (estimates rotation via luminance analysis).

### Healing
- Modes: Spot / Heal / Clone.
- Brush size 5..200, feather 0..100.
- Clone source set via Alt/Option+click (Clone mode).
- Space+drag pans while healing.
- Spot selection + source pin drag; Delete/Backspace removes selected spot.

### History
- Undo/redo buttons + shortcuts (`Cmd/Ctrl+Z`, `Shift+Cmd/Ctrl+Z`).
- Clickable history list (time travel) + baseline reset.
- Debounced commits (~250ms).

### Placeholders / partial features
- Buttons in Basic section: Auto / B&W / HDR appear present but do not perform actions.
- "Profile" section is a disabled empty input.
- Guided Upright UI is present, but the actual guided line workflow appears unimplemented.
